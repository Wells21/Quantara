Execution Quality — Cost Drag Drill-Down

Where real dollars are lost between the Gate A/B/C cost_bps assumption and the live fill

Gate A/B/C's cost_bps is a single spread assumption applied once at entry. It has no model for (a) real slippage between planned and actual fill price, (b) overnight swap/financing on trades held longer than typical, (c) commission. All three are real, per-trade dollars in the closed-trade ledger, converted here into R units (÷ planned_risk_usd) so they're directly comparable to the drift deltas above. This is expected friction, not necessarily edge decay -- the root-cause line under each flagged edge above estimates how much of its drift this friction can and can't explain.

Deep-Dive: Streak & Small-Sample Noise

Is this a normal losing streak this edge's own backtest already knows about, or something else?

Two checks per edge, both using ONLY that edge's own real backtest sample: (1) compare the live book's current consecutive-loss streak against the worst streak that geometry ever produced in its full backtest history; (2) resample 3,000 random windows of the same size as the live sample from the backtest, to see how often a window this small produces a mean this extreme just from noise. Shown for every edge with 2+ live trades, not only flagged ones, so you can watch the picture sharpen as more trades fire.
