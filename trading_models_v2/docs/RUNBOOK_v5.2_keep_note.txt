  portfolio_allocator/config/broker_profiles/<firm>_cost_models/<ASSET>.json
GATE A (signal existence), exactly this grid (405 cells):
  python shared/research/v3_horizon_lab.py --edge-root <edge> --hybrid-fast-grid --save
   --event-vol-lookbacks 1,2,4,6,8 --event-vol-ewm-spans 20,50,100
   --vertical-horizons 1,2,4,8,16,24,48,96,168 --barriers 1:1,1.5:1,2:1 --cost-bps <MODEL MEAN>

  Use ONLY the fresh grid CSV (old grids in the folder may be pre-v5 / bar-count).
GATE C (authoritative):
  python shared/research/v3_horizon_lab.py --edge-root <edge> --execution-finalists <ALL cells>
   --execution-entry-delay-ms 5700 --execution-bootstrap-reps 2000 --save
   --execution-spread-model broker --execution-cost-model <firm>_cost_models/<ASSET>.json
  Exact tick replay on the Dukascopy mid with the broker's modelled spread (FIXED_POINTS or
  hour-of-week x vol-tercile TABLE), swap per rollover crossed, commission. Extra cost = 0.
  WINNER = argmax compound_velocity_score among exec_mean_R > 0 (coverage >= 99%).
  None positive = KILL.

  Prob[OOS<=0] < 0.5. Otherwise KILL. (User may allow a borderline edge to Gate D explicitly.)

LOCK the winner in ALL places:
  1. candidate_events.py: EVENT_VOL_LOOKBACK_HOURS, EVENT_VOL_EWM_SPAN
